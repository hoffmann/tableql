Example Queries

  • age >= 30 - Find people 30 or older
  • city:Berlin - Find people in Berlin
  • city:Berlin age >= 30 - Berlin residents 30 or older (AND)
  • city:Berlin OR city:Munich - People in either city (OR)
  • name ~= ^A - Names starting with A (regex on string)
  • age ~= ^3 - Ages starting with 3 (regex on number: 30, 35)
  • created ~= ^2025 - Dates in 2025 (regex on date)
  • Alice - Free-text search (finds in any string field)
  • active - Boolean field shorthand (finds all active users)
  • true - Free-text search for boolean true (any boolean field)
  • false - Free-text search for boolean false (inactive users)
  • 30 - Free-text search for number (matches age 30)
  • 2025 - Free-text search for date (matches dates containing 2025)
  • ORDER BY age ASC - Sort by age, youngest to oldest
  • ORDER BY age DESC - Sort by age, oldest to youngest
  • ORDER BY name ASC - Sort alphabetically by name
  • age >= 30 ORDER BY age DESC - People 30+ sorted by age descending
  • city:Berlin ORDER BY age ASC - Berlin residents sorted by age
  • active = true ORDER BY name ASC - Active people sorted by name
  • active = false - Filters on the raw value behind the ❌ emoji (data-value)
  • progress >= 0.8 - Filters on the raw percentage behind the bar (data-value)
  • progress >= 0.8 ORDER BY progress DESC - High-adoption rows, sorted by the bar value
